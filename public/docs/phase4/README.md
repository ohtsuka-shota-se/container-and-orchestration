# Phase 4：Docker Swarm

## 概要

| 項目 | 内容 |
|---|---|
| 対象 | Phase 3 修了者 |
| 想定時間 | 4〜6 時間 |
| 形式 | 座学 + ハンズオン + シナリオ演習 |

## シナリオ（Phase 4 全体）

> アプリが成長し、1 台のサーバーでは捌ききれなくなってきた。  
> 複数サーバーに分散させて、1 台落ちても自動復旧する構成を作ろう。
