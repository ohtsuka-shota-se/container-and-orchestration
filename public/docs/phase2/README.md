# Phase 2：イメージ作成・管理

## 概要

| 項目 | 内容 |
|---|---|
| 対象 | Phase 1 修了者 |
| 想定時間 | 4〜6 時間 |
| 形式 | 座学 + ハンズオン + シナリオ演習 |

## シナリオ（Phase 2 全体）

> 自社の Python アプリをコンテナ化して、チームに配布したい。  
> 「動く環境ごと渡せる」状態を目指そう。

## 習得できること

- [ ] Dockerfile の主要命令を書ける

- [ ] マルチステージビルドでイメージサイズを削減できる

- [ ] プライベートレジストリを構築できる
